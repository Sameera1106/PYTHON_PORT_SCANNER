# Python Port Scanner

A beginner-friendly Python TCP port scanner built for cybersecurity and networking learning.

## Features

- Scan a single IP address or hostname
- Scan a specified range of TCP ports
- Display only open ports
- Validate IP addresses and port numbers
- Handle connection errors and timeouts
- Identify basic services running on open ports

## Technologies Used

- Python 3
- Socket programming
- TCP/IP networking

## How to Run

Make sure Python 3 is installed.

Run the scanner from the project directory:

```bash
python scanner.py
